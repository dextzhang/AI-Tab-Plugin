# AI2tab 使用文档

## 简介

AI2tab 是一款 Chrome 浏览器扩展程序，支持在一个页面输入消息后，**同步发送到多个AI模型网页**。

支持平台：
- ChatGPT (chat.openai.com, chatgpt.com)
- Google Gemini (gemini.google.com)
- X.ai Grok (x.ai, grok.com)
- 阿里云通义千问 (tongyi.aliyun.com)
- 字节跳动豆包 (doubao.com)
- Kimi (kimi.moonshot.cn)

---

## 安装方法

1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目文件夹 `TabPlugin`

---

## 使用方法

### 1. 发送文本消息

1. 在浏览器中打开多个AI网站标签页
2. 点击扩展图标打开弹窗
3. 在文本框中输入问题
4. 点击「发送消息」按钮
5. 扩展会自动：
   - 在每个AI网站新建对话
   - 选择对应的模型（专家模型/深度思考等）
   - 输入内容并发送

### 2. 生成图片

1. 切换到「图片生成」标签
2. 输入图片描述
3. 选择图片尺寸
4. 点击「生成图片」按钮

## 调试与问题排查

### 查看日志

1. 打开AI网站（如豆包、通义千问）
2. 按 `F12` 打开开发者工具
3. 切换到「控制台」标签
4. 搜索 `[TabPlugin]` 开头的日志

### 常见问题

**Q: 某个AI网站没有反应怎么办？**

A: 
1. 检查该AI网站是否已打开（需要保持标签页打开）
2. 打开该网站的开发者工具，查看控制台是否有 `[TabPlugin]` 相关日志
3. 如果没有任何日志，可能是脚本注入失败
4. 尝试刷新该AI网站页面后再次发送

**Q: 为什么选择模型的步骤有时会失效？**

A: 各AI网站的UI经常更新，选择器可能需要同步更新。如果发现模型选择失败，请提交问题反馈。

**Q: 如何查看发送结果？**

A: 发送完成后，弹窗底部会显示成功/失败数量和具体原因。

## 注意事项

1. **保持标签页打开**：发送消息时，所有目标AI网站的标签页必须保持打开状态
2. **网络要求**：需要能够正常访问各AI网站
3. **登录状态**：各AI网站需要保持登录状态
4. **页面加载**：发送消息后会自动新建对话，需要等待页面加载完成

---

## 后续建议

如果某些AI网站仍然无法正常使用，可以考虑：

1. **增加等待时间**：在 `content.js` 中调整 `delayAfterNewChat` 的值
2. **更新选择器**：各AI网站UI更新后，可能需要更新 `AI_PLATFORMS` 中的选择器
3. **添加新平台**：可以参照现有平台的配置添加新的AI网站
4. **使用油猴脚本**：可以参考 Multi-AI Assistant 的实现方式，它对国产AI支持较好
